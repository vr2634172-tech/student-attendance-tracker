# Student Attendance Tracker

A simple browser-based project to add students and track attendance.

## Features
- Add student names
- Mark each student Present or Absent
- View attendance counts and percentage
- Save the list in the browser using local storage

## Technologies
- HTML
- CSS
- JavaScript

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Add student names and mark attendance.

## Files
- `index.html` — page layout
- `style.css` — styling
- `script.js` — attendance functionality

## Note
This is a learning/demo project. Data is saved only in the current browser on the current device. It does not use a server or shared database.
